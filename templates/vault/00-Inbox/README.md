# 00-Inbox

Continuidad entre sesiones de Claude Code: qué se estaba haciendo, en qué punto se
quedó, y qué sigue. Categoría `personal`, tag `personal/sesion`.

La escribe el ritual `ritual.mjs fin-sesion` al cerrar una sesión de trabajo — no se
edita a mano, salvo para completar la plantilla vacía que el ritual deja cuando se
invoca sin `--resumen`.

Ejemplo de qué va aquí (`2026-08-02-1730-claudemax.md`):

> Se implementó el backend kaggle; falta probar el timeout del poll. Siguiente
> paso: escribir el test de integración.

Qué NO va aquí: bitácoras del día completo (eso es `Journal/`), ni notas ya
clasificadas por tema — una vez el contenido de una sesión interesa a largo plazo,
muévelo a la carpeta que corresponda.
