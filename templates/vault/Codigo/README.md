# Codigo

Repos, arquitectura, snippets y grafos de conocimiento de Graphify. Categoría
`codigo`. Una subcarpeta por repo (`Codigo/<repo>/`).

Ejemplos de qué va aquí:
- `Codigo/claudemax/arquitectura.md`: decisiones de diseño del RAG, esquema de BD.
- `Codigo/claudemax/snippets.md`: fragmentos de código reutilizables.
- Grafos `.ua/knowledge-graph.json` de cada repo — los indexa `rag.mjs ingest`
  directamente desde el repo, no hace falta copiarlos aquí.

Qué NO va aquí: planes o decisiones de negocio de un proyecto (eso es
`Proyectos/`).
