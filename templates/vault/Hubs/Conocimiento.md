# Conocimiento

Referencia estable: normativas, manuales, convenciones de código, comparativas, PDFs parseados,
transcripciones — lo que se consulta para decidir o para hacer bien algo. Colección
`conocimiento`, autoridad `referencia`.

## Cuándo nace una nota aquí
Cuando algo externo (una norma, un manual, una investigación) se destila para tenerlo a mano. Si
la nota describe un documento o código concreto, declara `fuentes:` para que el RAG avise cuando
la fuente cambie; si tiene fecha de caducidad, `revisar:`.

## Qué NO va aquí
Lecciones de errores propios ([[Aprendizaje]]) ni palabras textuales de una persona
([[Entrevistas]]).
