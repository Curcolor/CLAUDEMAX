# Journal

Bitácoras: registro cronológico del trabajo diario. Categoría `personal`, tag
`personal/bitacora`. Un archivo por día (`YYYY-MM-DD.md`), con una entrada nueva por
hora (`## HH:MM`).

La escribe el ritual `ritual.mjs fin-dia` — puede llamarse varias veces al día y
cada llamada añade una entrada nueva sin pisar las anteriores.

Ejemplo de qué va aquí (`2026-08-02.md`):

> ## 18:05
> Terminado el refactor del parser de frontmatter; añadidas pruebas.

Qué NO va aquí: el resumen de continuidad entre sesiones de Claude Code (eso es
`00-Inbox/`, lo escribe `fin-sesion`).
