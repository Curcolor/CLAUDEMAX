# Organizacion

Parte legal y conceptual de la organización. Categoría `organizacion`.

Ejemplos de qué va aquí:
- Miembros y roles del equipo.
- Estatutos, contratos, marca (identidad, guidelines).
- Procesos internos (onboarding, políticas).
- Clientes (datos de contacto, acuerdos).

Qué NO va aquí: el trabajo técnico o de producto de un proyecto concreto (eso es
`Proyectos/` o `Codigo/`), aunque compartan `proyecto` como clave transversal para
quedar relacionados en el RAG.
